💾 数据备份

你的所有数据都存在这台手机的浏览器里，不在任何服务器上。
换手机、清理浏览器数据前，记得先导出备份。

☁️ 云同步

手机和电脑填同一个密钥，看到的就是同一份数据（灵感、计划、提醒、数据全同步）。
存在你自己的 GitHub 私有片段里，不经过任何第三方服务器。
填一次就永久记住，之后不用再登录、不用输密码。断网照样能记，联网自动补上。

✅ 这台设备已连接，以后打开就是登录状态，不用再填密钥。
上次同步：
在 GitHub 上看云端那份 →

改动 4 秒后自动上传；切回页面自动拉取。新手机只需在这里再粘一次密钥即可。

📁 本机素材目录

填你放视频和脚本的总文件夹，电脑上一键打开素材就靠它。
例：E:\短视频素材
